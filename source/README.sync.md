# Canonical source

This Git repository is the authoritative source for Cave UI. Edit `tokens.json`,
`components/core.css`, `catalog.mjs` and the package source here. Build and test
before release. Do not overwrite this directory from an external AI artifact.

The initial design was imported from a Cave design artifact. Legacy component
previews and brand files are retained for reference and site identity; the package
build uses explicit allowlists and excludes proprietary fonts, logos and product
patterns. Versioned package outputs are generated by `scripts/build-packages.mjs`.
